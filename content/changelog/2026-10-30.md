# Changelog: Oct 23 – Oct 30, 2026

## MCP v2: 25 tools instead of 42
Read-only lookups are folded into two tools, `inspect` and `list`, so agents pick the right tool faster. Write tools stay explicit, and destroy and restore stay separate. Old tool names keep working.

## Scoped access for agents and tokens
OAuth access now comes in three levels: `paas:read` (view only), `paas:write` (deploy, scale, config, but no deleting apps or restoring backups) and `paas:admin` (everything). Scopes are enforced on the server in both MCP and the API. The Authorize page shows exactly what an app is asking for and lets you narrow it. CI deploy tokens can no longer delete anything unless you create them with `--allow-destroy`, and the CLI and dashboard now show which tokens have destroy rights.

## Release status tells the truth
Status, diagnose and deploy now show the release you asked for next to the release that's actually serving, plus health and a warning when they don't match. MCP `deploy_app` can wait for the deploy to finish.

## Smoother first deploys
- Aloof warns you when a deployed app isn't answering on its port, instead of showing it as live.
- The dashboard deploy form sets port 80 automatically for nginx, httpd and Caddy images.
- The template deploy page prefills a name, shows plan and region, and keeps generated secrets on screen.
- Destroying a template app also removes the volumes and Postgres it created.
- Git deploys with a deploy key give clearer hints when the fetch is rejected.

## Security
Containers can't reach the cloud metadata service, session and platform cookies use `__Host-` names, login and magic-link rate limits count IPv6 per /64, and email addresses are never sent to analytics.
