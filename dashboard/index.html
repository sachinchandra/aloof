API keys

Keys let tools act on your account without your password. Treat them like passwords: we only store a hash, so a key is shown once when it's created.

CLIDeploy, tail logs and scale from your terminal with aloof.
MCP for AI agentsLet Claude, ChatGPT or Cursor deploy for you. Remote connectors sign in with OAuth; local servers use a key.
REST APIAutomate anything with Authorization: Bearer. See the API reference.

Full access keys (pk_) can do everything your account can, including billing. Deploy tokens (dt_) are limited to one app or all apps, can expire, and can't manage keys, billing or auth: prefer them for CI.
